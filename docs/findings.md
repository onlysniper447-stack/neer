# Verification findings

This is the complete **69-code public union** at verifier version 1.0.0, currently local and unreleased. Positive/info legacy diagnostics are not public findings. HTTP validation errors are not finding codes; see [API](api.md).

## Reading exact messages

Literal text below is exact. For dynamic messages, `${expression}` denotes the **exact source template expression**, evaluated at runtime, not literal output. Nested template strings, fallbacks, plurals and formatting are preserved. HTML entities only escape Markdown/HTML characters. See [rule source](../packages/core/src/checks.ts) and [fallback source](../packages/core/src/preflight.ts).

The `where` variable in address messages is either "This" (pasted address) or "The address you're sending to" (declared/decoded send address). `fmtOrigin` uses token decimals/symbol or base units without metadata; `humanDuration` renders under a minute, minutes, hours/minutes or days. Network names and shortened addresses come from the existing chain/address helpers. These are data-dependent variants, not additional codes.

Unknown required checks map to public warn, never pass. QUOTE_UNAVAILABLE maps to block even though its legacy severity is unknown. TOKEN_CONTRACT_MISMATCH can block with a decoded draft or warn otherwise. REQUIRED_CHECK_MISSING can also block when the projection detects a contradictory internal block result. Fixes are guidance, not recovery/delivery promises. Some codes require legacy-only context or injected failures; the [fixture README](../fixtures/quotes/README.md) identifies these explicitly.

## Stability

Codes are never renamed or removed, including across major releases. A retired condition keeps its code reserved and documented. Wording may change in patch releases; consumers must branch on code/severity, not message text. This baseline intentionally changes no existing message or snapshot. New codes require documentation, fixtures and a version entry before release. See [versioning](versioning.md), [limits](limits.md) and [changelog](../CHANGELOG.md).
